# Internet Plays Pokémon

Internet Plays Pokémon is a .NET application allowing users to play Pokémon games through a livestream chat. Built with C# and Avalonia to be run on Windows, Linux, and MacOS, it includes a graphical chat interface to be included on stream.

## Installation

Download the latest release from the [Releases page](https://github.com/jwedison/Internet-Plays-Pokemon/releases). Currently, the application is only available as a pre-built binary for Windows. Linux and MacOS builds are planned for future releases.

## Usage

Open the settings menu (Ctrl + ,) to configure the application. Select the streaming platform you are using (Twitch, YouTube currently supported) and enter your username, then click Save.

The application will display all messages from the chat in a graphical interface. Users can type commands in the chat to control the game, such as "up", "down", "left", "right", "A", "B", etc. The application will press the corresponding buttons in the game based on the commands received from the chat. For this to work, you will need to have your emulator controls set as follows:
- Up: Up Arrow
- Down: Down Arrow
- Left: Left Arrow
- Right: Right Arrow
- A: A
- B: B
- Start: Return/Enter
- Select: Space
- L: L
- R: R
